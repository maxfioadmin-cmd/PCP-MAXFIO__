⚡ Supabase — Sincronização em tempo real ⚫ Não conectado

Cole a URL e chave anon do seu projeto Supabase para sincronizar todos os usuários em tempo real.
Gratuito até 500MB. Criar em: supabase.com

▶ Como criar o projeto (5 passos)
  1. Acesse supabase.com → "Start your project" → login com GitHub
  2. "New project" → nome pcp-maxfio → região South America (São Paulo) → Create
  3. SQL Editor → "New query" → cole o SQL abaixo → Run
  4. Settings → API → copie Project URL e anon public key
  5. Cole os valores abaixo → Salvar e Conectar → Subir dados locais
create table pcp_sync ( chave text primary key, dados text, atualizado_em timestamptz default now() ); alter table pcp_sync enable row level security; create policy "Acesso total" on pcp_sync for all using (true) with check (true); alter publication supabase_realtime add table pcp_sync;
